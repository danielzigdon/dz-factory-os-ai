# DESIGN-01-PREVIEW — הפעלת האבטיפוס לבעל המפעל

**סטטוס:** אבטיפוס הדגמה בלבד. **זו לא מערכת Production.** כל הנתונים בדויים. אין חיבור ל-Priority, אין מסד נתונים, ואין שמירה של מידע.
נקודת התחלה: `a7807529`. העיצוב לא שונה. נוספה רק בדיקה, `tests/preview.spec.ts`.

## 1. קישור חיצוני
**לא נוצר קישור חיצוני.** סביבת הפיתוח היא קונטיינר בענן שמאפשר רק תעבורה יוצאת דרך proxy. אין בה כלי tunnel, ואין אפשרות לקבל חיבורים נכנסים מהאינטרנט. כל קישור חיצוני מחייב **פריסת Preview חיצונית**, ולפי ההנחיה היא דורשת אישור מפורש לפני ביצוע. האפשרויות מפורטות בסעיף 5.

## 2. הפעלה מקומית במחשב Windows

**דרוש פעם אחת:**
- **Node.js 22 LTS** מ-https://nodejs.org: בוחרים "LTS" ומתקינים עם ברירות המחדל.
- **Git for Windows** מ-https://git-scm.com/download/win.
- הריפו פרטי, ולכן בפעם הראשונה Git יבקש התחברות ל-GitHub. זה צריך להיות חשבון עם גישה ל-`danielzigdon/dz-factory-os-ai`.

**פותחים PowerShell ומריצים:**
```powershell
git clone https://github.com/danielzigdon/dz-factory-os-ai.git
cd dz-factory-os-ai
git checkout claude/new-session-31hftf
cd prototypes\design-01
npm ci
npm run build
npm run start
```

**פותחים בדפדפן:** http://localhost:3100/s01

| מסך | כתובת |
|---|---|
| S01 — לוח מנהל | http://localhost:3100/s01 |
| S02 — מרכז פניות | http://localhost:3100/s02 |
| S03 — כרטיס לקוח | http://localhost:3100/s03/C-101 |

- **עצירה:** Ctrl+C בחלון PowerShell.
- **הפעלה חוזרת:** `npm run start` מתוך `prototypes\design-01`. ההתקנה וה-build נדרשים רק פעם אחת.
- **עדכון לגרסה חדשה:** `git pull`, ואחריו `npm ci`, `npm run build` ו-`npm run start`.

**בדיקה בטלפון באותה רשת Wi-Fi (אופציונלי):** במקום `npm run start` מריצים `npx next start -p 3100 -H 0.0.0.0`. מוצאים את כתובת ה-IP של המחשב עם `ipconfig` (שורת "IPv4 Address"), ופותחים בטלפון `http://<כתובת-IP>:3100/s01`. Windows עשוי לשאול על חומת האש: מאשרים **רשת פרטית בלבד**. כך האבטיפוס זמין לכל מכשיר ברשת המקומית, בלי סיסמה, ולכן כדאי לעשות זאת רק ברשת הביתית או המשרדית.

## 5. אפשרויות לקישור חיצוני (דורשות אישור מפורש)
1. **עמוד פרטי ב-claude.ai (Artifact):** פרטי כברירת מחדל, ונפתח רק לחשבון שלך או למי ששותף איתו. מחייב התאמה: גרסה סטטית של האבטיפוס. בגרסה כזו נתוני "מנהל" נכללים בקובץ, ולכן ההדגמה של הסתרת הנתונים בשרת **לא תהיה אמיתית**, אלא חזותית בלבד. אין סיסמה נפרדת: הגישה מוגבלת לפי חשבון.
2. **Vercel Preview:** פריסה של הענף כפי שהוא, כולל הסתרת הנתונים בשרת. הגישה מוגבלת להתחברות Vercel (חינם) או לסיסמה (תכונה בתשלום). דורש חשבון Vercel וחיבור לריפו מצדך.
3. **הפעלה מקומית** (סעיף 2): בלי חשיפה חיצונית בכלל.
